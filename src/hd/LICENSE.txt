HD look assets (hd/*.glb), used in DUSTREACH only

All models by Quaternius (https://quaternius.com):
  - Universal Base Characters (Standard), Modular Character Outfits - Fantasy (Standard),
    Universal Animation Library (Standard): downloaded 2026-11-23, licence file in the packs: CC0 1.0
  - weapons.glb: Sci-Fi Guns (May 2018), Animated FPS Guns (Jun 2018), Medieval Weapons (Sept 2018),
    RPG Asset Pack (May 2017) free packs, converted from FBX with three.js FBXLoader + GLTFExporter
  - mech.glb: Animated Mech Pack (Mar 2021, CC0): Stan, Mike, Leela; wolf.glb: Ultimate Animated Animals (CC0): Wolf
    (downloaded 2026-11-24, packed by tools/hd/beasts.mjs)
  - ship.glb: LowPoly Spaceships (Jan 2018) free pack, Spaceship5, converted the same way (downloaded 2026-11-24)
  - bestiary.glb: Bestiary - Dungeon Monsters Kit (Source tier, bought 2026-11-26, Quaternius Asset License v1.0):
    Hellwarden, Imp, Lycan, Puglin, Skeleton_A, Skeleton_B, Tidebreaker (packed by tools/hd/bestiary.mjs). Paid assets:
    the original pack (zip, .blend, full-size textures) is not in this repo and must not be added.
  - scifi.glb: Modular Sci-Fi MegaKit (Source tier, bought 2026-11-26, Quaternius Asset License v1.0): 32 wall, floor,
    column and prop pieces (packed by tools/hd/scifi.mjs). Paid assets: same rule, the original pack is not in this repo.
Quaternius's current licence (Quaternius Asset License v1.0) also allows use in games, free, no credit required,
but not re-distributing the models as an asset pack. These files are part of the game: please don't extract
them for reuse; get them from quaternius.com instead.
Packed by tools/hd/pack.mjs and tools/hd/weapons.mjs (textures resized to JPEG, meshes quantised, animations trimmed).
